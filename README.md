# Close Enough Construction V3

Version 3 expands the free installable PWA into a more complete customer + crew project portal.

## V3 additions
- Customer portal shortcuts
- Payment requests and due dates
- Printable / saveable payment receipts
- Job checklist and completion tracking
- Change orders with customer approval
- Automatic estimate update after approved change orders
- In-app project notifications
- Improved project workflow

## Still included
- Owner / Crew / Customer demo views
- Create and name jobs
- Estimate approval
- Invoice / estimate numbers
- Payment history
- Scheduling and crew assignment
- Job chat
- Project photos
- Status tracking
- Installable PWA / offline shell

## Important
This is still a local-device prototype. Data is stored in browser localStorage.
Real card processing is NOT enabled. Do not place secret Stripe keys in this app.

The next major architecture step is a secure cloud backend for:
- real user login accounts
- shared owner / crew / customer data
- cloud photos
- real-time chat
- secure payment checkout
- push notifications
